# Monato Esprit Atlas

Двуязычный справочник Monato Esprit: локации, NPC и услуги, монстры,
боссы, добыча, экипировка, крылья, зелья, квестовые цепочки и умения.

**Сайт:** https://pavlovich-kll.github.io/monato-esprit-atlas/

## Публикация

Готовый статический сайт находится в `site/`. GitHub Actions публикует
его на GitHub Pages после обновления ветки `develop`. Сборка и отдельный
сервер не требуются. Посетителям не нужен аккаунт GitHub.

Для обновления замените нужные файлы в `site/` и отправьте изменения в
`develop`. Публикацию также можно запустить вручную через Actions →
Publish Monato Esprit Atlas → Run workflow.

## Локальный просмотр

```sh
python -m http.server 8000 --directory site
```

Откройте http://localhost:8000/. Пути к ресурсам относительные; разделы
используют навигацию через `#`, поэтому работают и в подпапке GitHub Pages.

## Данные и изображения

Карточки содержат сведения из ресурсов клиента и отдельно обозначенные
настройки восстановленного сервера. Неустановленные параметры помечены.
Изображения используют исходные игровые ресурсы; предпросмотры моделей
статические и не воспроизводят анимацию, частицы и свечение.

JSON-аудиты в `site/` фиксируют происхождение и проверки данных.
Сохранения игроков, серверные модули и данные авторизации сюда не включены.

## Доступ к локациям и подземельям: 08.10.2026

В28 карточках локаций и37 вариантах добавлены уровни и условия входа на восстановленном сервере. Аудит включает92 исходных правила (77 включённых,15 неполных/выключенных) и4 отдельные правила старта/Реи/свитка. Для каждого маршрута показаны исходная карта, NPC или портал, уровень, цена, предмет и квест. Архивным незарегистрированным вариантам доступ современной версии не присваивается.

Основной мир требует завершённого500000003 «Продвинутые уроки» (с5-го уровня) и доступа аккаунта; первый переход в Isildra расходует свиток50000. Rhea502 требует активный или завершённый500010001; остальные проверенные входы не добавляют отдельного квеста поверх общего доступа. Первый склад имеет собственный порог3, но эффективный вход5 из-за стартового квеста. У телепорта и пешего маршрута могут быть разные пороги. Уровни монстров не используются как уровни входа.

Минимум по полной известной цепочке вычисляется minimax по включённым переходам. Если цепочка от старта не подтверждена, показана только нижняя граница конкретного входа; если самого входа нет, порог не выдумывается. Отдельно отмечен выключенный4→5 и входы без исходных областей активации.

Источники и SHA: `site/location-access-audit.json`. Обновление и проверка RU/EN:

```sh
python tools/update_location_access.py /path/to/monato-restoration-server-plan
node tools/check_location_access.cjs
```
