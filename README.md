# Monato Esprit Atlas

Двуязычный справочник Monato Esprit: локации, NPC и услуги, монстры,
боссы, добыча, экипировка, крылья, зелья, квестовые цепочки и умения.

**Сайт:** https://pavlovich-kll.github.io/monato-esprit-atlas/

## Публикация

Готовый статический сайт находится в `site/`. GitHub Actions публикует
его на GitHub Pages после обновления ветки `develop`. Сборка и отдельный
сервер не требуются. Посетителям не нужен аккаунт GitHub.

Для обновления замените нужные файлы в `site/` и отправьте изменения в
`develop`. Публикацию также можно запустить вручную через Actions →
Publish Monato Esprit Atlas → Run workflow.

## Локальный просмотр

```sh
python -m http.server 8000 --directory site
```

Откройте http://localhost:8000/. Пути к ресурсам относительные; разделы
используют навигацию через `#`, поэтому работают и в подпапке GitHub Pages.

## Данные и изображения

Карточки содержат сведения из ресурсов клиента и отдельно обозначенные
настройки восстановленного сервера. Неустановленные параметры помечены.
Изображения используют исходные игровые ресурсы; предпросмотры моделей
статические и не воспроизводят анимацию, частицы и свечение.

JSON-аудиты в `site/` фиксируют происхождение и проверки данных.
Сохранения игроков, серверные модули и данные авторизации сюда не включены.
